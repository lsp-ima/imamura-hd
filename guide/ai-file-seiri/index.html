AIでファイル整理をする手順。名前のルールを先に決めて、1フォルダずつ任せる

公開: 2026年11月11日 ／ 最終更新: 2026年11月11日 ／ 合同会社LSP「AIの育て方」

「AI ファイル整理」で調べている人に向けて書いています。 書類のファイル名がばらばらで、探すたびに開いて確かめている。その整理は、AIに任せられます。ただし最初に、名前のルールだけは人が決めます。

AIにファイル整理を任せると、何ができるんですか？

ファイルの名前をそろえることと、決めた場所に分けることです。 中身を読んで「これは契約書」「これは見積書」と見分けて、名前を付け直し、フォルダに振り分けます。

人がやると1件ずつ開いて確かめる仕事を、AIがまとめてやります。 ただし、最初にやるのはAIではなく人です。どういう名前にそろえるかを、先に決めておく必要があります。

何から始めればいいですか？

名前のルールを1行で決めます。 
日付(年月日)_種類_相手の名前_中身.pdf
例: 20261111_見積書_山田様_外壁塗装.pdf

ルールが決まっていないままAIに頼むと、その場その場で違う名前を付けます。整理したつもりが、別の形でばらばらになります。

AIへの頼み方は？

ChatGPTなどに、このまま貼れます。 
このフォルダのファイル一覧を渡します。
次のルールで新しいファイル名を考えて、「今の名前 → 新しい名前」の表にしてください。
ルール: 日付(年月日)_種類_相手の名前_中身
・日付が分からないものは「日付不明」と書く
・種類は 見積書/契約書/請求書/写真/その他 のどれか
・決められないものは表の最後にまとめて、理由を1行で書く
まだファイルは動かさないでください。表だけ出してください。

最後の「まだ動かさない」が大事です。まず表で確かめて、合っていたら次に進みます。

実際に名前を変えるところまで、AIにやらせられますか？

できます。ただ、ChatGPTの画面だけではパソコンの中のファイルは動かせません。

パソコンの中で作業できるAI(Claude Code など)を使うと、表のとおりに名前を変えて、フォルダに振り分けるところまでやります。

そのときは、必ず先にフォルダごとコピーを取っておいてください。名前を変えたあとで「元はどれだったか」が分からなくなるのが、一番困るからです。

うまくいかないのは、どんなときですか？

3つあります。
  • ルールが決まっていないとき。毎回違う名前になります。
  • 一度に全部やろうとしたとき。最初は1フォルダ、20件くらいで試して、ずれ方を見てからにしてください。
  • 中身を見ないと分からないファイルが多いとき。写真やスキャンした紙は、読み取れずに「その他」に入ることがあります。そこは人が見ます。

自分の仕事だと、何から任せればいいですか？

ファイル整理が合うかどうかは、仕事によって違います。

3問に答えると、あなたの仕事で最初に任せる1つと、そのまま貼れる指示文が出ます。登録はいりません。

あわせて読む: 個人事業主のAI活用。最初に任せる3つの仕事と、任せない仕事／AIでメール返信を自動化する指示文のひな形と、効かなくなる場面
